About the Platform

SPRIX is an educational portal for secondary school students that provides programming and information technology content.

The portal includes a textbook, a programming platform, TOFAS tests, and results and certificates.

QUREO is connected to the programming learning experience available through SPRIX.

What Can You Learn?

Programming Basics

Learn programming fundamentals and problem-solving concepts.

Python

The textbook includes a chapter dedicated to Python programming.

Visual Programming

Learn visual programming concepts through interactive learning.

Algorithms and Problem Solving

Develop logical thinking and understand problem-solving steps.

Databases

Learn about databases and their role in information technology.

Networks and Communications

Learn about networks, communication, and information transfer.

Data Analysis

Learn the basics of data analysis and understanding information.

Simulation

Learn how simulations can be used to study systems and problems.

Information Security

Learn the basics of information security and data protection.

SPRIX + QUREO Features

Interactive Learning

SPRIX Learning uses a story-based and game-based approach to teach programming fundamentals.

Practical Learning

Programming activities help students turn concepts into practical skills.

Electronic Textbook

The textbook is available electronically through the SPRIX portal.

TOFAS Assessment

TOFAS provides standardized assessment of programming skills and available results and certificates.

Benefits for Students

Programming Foundation

Helps students understand programming and information technology fundamentals.

Logical Thinking

Programming and problem-solving activities give students practice in logical thinking.

Preparation for Advanced Learning

Programming knowledge can provide a foundation for later technical learning.

Skill Assessment

TOFAS can be used to assess programming skills.

How to Access

1. Open the SPRIX website.

2. Choose your grade.

3. Choose Programming and IT.

4. Choose the programming platform.

5. Click Login.

6. Continue to QUREO if you are redirected there.

7. Use the credentials provided by your educational authority or school when requested.
