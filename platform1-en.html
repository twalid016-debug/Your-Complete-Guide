SPRIX + QUREO

An educational platform for secondary school students that combines programming, information technology, and interactive learning.

Visit SPRIX

About the Platform

SPRIX is an educational portal for secondary school students that provides programming and information technology content.

The platform includes an electronic textbook, a programming learning platform, TOFAS tests, results, and certificates.

When students access the programming platform through SPRIX, they can be redirected to QUREO for programming learning.

What Can You Learn?

Programming Basics

Learn programming fundamentals and how to solve problems using code.

Python

The educational content includes a full chapter about Python programming.

JavaScript

Learn about JavaScript and some of its uses in programming and web development.

Visual Programming

Learn visual programming concepts such as Scratch.

Algorithms and Problem Solving

Develop logical thinking and learn how to design steps for solving problems.

Databases and Networks

Learn about databases, networks, communication, and information transfer.

Data Analysis and Simulation

Learn about data analysis and the use of simulations to study systems and problems.

Information Security

Learn the basics of protecting information and using technology safely.

SPRIX + QUREO Features

Interactive Learning

Stories and game-based activities make the learning experience more interactive.

Practical Programming

Students can apply programming concepts instead of relying only on theory.

Electronic Textbook

Students can access the educational content and electronic textbook.

TOFAS Assessment

TOFAS tests can be used to assess skills and provide results and certificates.

Benefits for Students

Programming Foundation

The platform can help students build a foundation in programming and IT.

Logical Thinking

Programming exercises and problem solving can develop logical thinking skills.

Preparation for Advanced Learning

Programming knowledge can help students prepare for advanced areas such as AI.

Skill Assessment

TOFAS tests provide a way to assess skills and view available results.

How to Access

1. Open the SPRIX website.

2. Choose your grade.

3. Choose Programming and IT.

4. Choose the programming platform.

5. Click Login.

6. You will be redirected to QUREO.

7. Use the credentials provided by your educational authority or school if requested.
