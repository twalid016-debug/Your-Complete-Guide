
دليل التثبيت والتشغيل - مشروع "دليل مصر الرقمية الشامل"

1. اللغات المستخدمة في بناء الموقع:
- HTML (لبناء هيكل الصفحات)
- CSS (لتنسيق التصميم والألوان)
- JavaScript (لإضافة التفاعلية والحاسبة)

2. متطلبات التثبيت والتشغيل:
- لا يحتاج الموقع إلى عملية تثبيت أو برامج خاصة.
- يتطلب وجود متصفح إنترنت (مثل Google Chrome أو Microsoft Edge).
- يتطلب الاتصال بشبكة الإنترنت للوصول إلى روابط المنصات الرسمية وحاسبة الخدمات.

3. خطوات تشغيل الموقع خطوة بخطوة:

الطرية الأولى (التشغيل عبر المجلد المحلي):
1. افتح مجلد (Source) الموجود داخل الفولدر الرئيسي.
2. اضغط مرتين على ملف (index-ar.html) لفتح النسخة العربية للموقع.
3. للنسخة الإنجليزية، اضغط مرتين على ملف (index-en.html).
